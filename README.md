# sudokuSolver

![nyoom](./public/assets/hoshi_demo.gif)

This is a console-based puzzle solver for the **Sudoku** puzzle.

## 👆 Try it out
- **[Click here!](https://bryrybry.github.io/hoshiBoshi)**
  
## 💡 Features
1. Presets to store and reuse boards
2. Step-by-step solver (also shows how each step is done)
3. Skip-to-the-end solver

Additionally, to find out more about **Sudoku**, you can check out the wiki page:
- https://en.wikipedia.org/wiki/Sudoku
